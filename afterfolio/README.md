# Young Planner

작업 엑셀 v1.1·본문 v11을 기준으로 부부의 은퇴자금을 월별 계산하는 웹 앱입니다. 입력 정보 확인 → 은퇴 계획 선택 → 결과 비교 흐름으로 사용합니다. 입력·대화는 자동 저장하지 않습니다.

## 로컬 실행

```sh
npm ci
cp .env.example .env.local
npm run dev -- --hostname 127.0.0.1 --port 3011
```

[로컬 화면](http://127.0.0.1:3011/)에서 예시 계산과 조건 변경을 바로 사용할 수 있습니다.

AI는 `.env.local`의 `GEMINI_API_KEY`와 `GEMINI_MODEL`, 또는 `OPENAI_API_KEY`와 `OPENAI_MODEL`로 연결합니다. 둘 다 있으면 Gemini 설정을 우선합니다. 키는 서버에만 설정합니다. `AI_ACCESS_TOKEN`을 설정한 환경은 첫 401 응답 때 나타나는 접근 토큰 입력란에 같은 토큰을 입력해야 합니다. 입력한 접근 토큰은 저장하지 않습니다.

## 기능

- ‘권 부장 부부 예시 넣기’ 버튼으로 예시 정보와 기본 계획을 채우고, ‘예시 소개’에서 가상의 부부 상황을 확인합니다.
- 생활비·자산, 가족, 월급·퇴직금, 연금으로 입력을 묶었습니다. 계산 가정과 저장 기능은 펼쳐서 사용합니다.
- ‘은퇴 계획’에서 구직급여·재취업·대출 상환·배우자 연금 추납·주택연금을 선택합니다. 항목마다 금액·기간을 조절합니다.
- 준비 전과 선택 계획의 자산을 같은 축에서 겹쳐 보거나 나란히 비교합니다. 명목금액과 기준년 구매력을 구분합니다.
- AI 에이전트는 계산 조회, 월별 수입·지출 조회, 변경안 비교, 제한된 조합 탐색 도구를 실행합니다. 변경 전후 조건과 수치를 후보 카드로 보여주며 사용자가 적용 버튼을 눌러야 반영합니다. 적용 직후 되돌릴 수 있습니다.
- Enter로 질문 전송, Shift+Enter로 줄바꿈합니다. 한글 조합 중 Enter는 전송하지 않습니다.
- API 미설정·오류·사용량 제한을 명확히 표시하고 재시도합니다. 계산 기반 설명으로 대체하지 않습니다.
- 레거시 화면과 이전 사례 전용 API·도구, 설명 전용 API를 제거했습니다. 기존 브라우저 저장 데이터는 삭제하지 않습니다.

화면의 금액·비율은 소수점 최대 한 자리로 표시합니다. 내부 계산과 JSON·검증 CSV 정밀도는 유지합니다.

## 검증과 자료

```sh
npm test
npm run typecheck
npm run build
npm run verify:report
```

원본 엑셀의 설계 전+E1~E6, 7개 안 × 410개월 금융자산을 1원 이내로 검증합니다. AI 도구의 입력 검증·조합 탐색·조건 고정·자동 적용 방지·오류·접근 보호도 테스트합니다.

- [사용 안내](docs/mvp-guide.md)
- [팀에 확인할 질문](docs/team-questions.md)
- [엑셀 대조표](docs/report-verification.csv)
- [이번 UI 개선 검증](docs/ui-ux-verification.md)

수익률은 준비 전과 선택 계획에 다르게 적용하는 보고서 가정을 유지합니다. 주택연금 채무·상속재산, 세금 정밀 계산, 실제 수급 자격은 계산 범위 밖입니다. AI 조합 탐색은 다섯 방법의 켜기/끄기와 제한된 주택연금 연도·연금 수령 시기를 비교하며 전역 최적해를 보장하지 않습니다. 생활비·수익률은 탐색 중 고정합니다.

AI 호출 제한은 서버 인스턴스 메모리 기준 1분 8회, 요청당 최대 6개 도구·4회 모델 호출입니다. 실제 AI 사용 가능 여부는 서버 설정과 제공자 계정의 한도에 따릅니다.

도구 호출 구조 참고: [OpenAI 공식 Function calling 문서](https://developers.openai.com/api/docs/guides/function-calling).
