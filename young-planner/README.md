# Young Planner

AFPK 영 플래너 챌린지 2026의 가상 고객 사례를 바탕으로 만드는 은퇴자금 시뮬레이터입니다.

목표는 월별 계산, 설계안 비교, 자연어 시나리오 변경, AI 설명, 검증 기록 내보내기를 제공하는 웹 앱입니다.

## 실행

```sh
npm ci
cp .env.example .env.local
npm run dev -- --port 3011
```

http://localhost:3011 에서 엽니다. 기본 계산과 비교·저장은 API 설정 없이 사용할 수 있습니다.

AI를 사용하려면 `.env.local`에 `GEMINI_API_KEY`, `GEMINI_MODEL=gemini-3.5-flash-lite`를 설정하고 서버를 재시작하세요. Gemini 무료 등급의 호출 한도를 적용하며 유료 서비스로 자동 전환하지 않습니다. OpenAI를 쓰려면 Gemini 키를 비우고 `OPENAI_API_KEY`, `OPENAI_MODEL`을 설정합니다. 배포 환경에서는 동일한 값을 Vercel 환경변수에 설정합니다. `AI_ACCESS_TOKEN`을 설정하면 AI 화면의 접근 설정에도 같은 토큰이 필요합니다. API 키는 브라우저에 입력하지 않습니다.

## 검증

```sh
npm test
npm run typecheck
npm run build
```

원본 엑셀의 6개 시나리오 × 410개월 금융자산을 0.0001만 원(1원) 이내로 대조합니다. 연금 부분 수정, 상환 월, 지출 충격, 재취업 지연과 API 설정·입력 오류를 검사합니다.

## 사용

- 기본안 선택 후 조건을 변경하면 지표·그래프가 갱신됩니다.
- 시나리오 비교에서 7개 기본안과 사용자 변경안을 비교합니다.
- JSON 저장·불러오기로 조건을 옮기고, CSV·PNG를 보고서 자료로 활용합니다.
- AI 질문은 현재 조건을 기준으로 처리하며 변경값과 계산 기록은 대화 JSON에 포함됩니다. AI는 직전 대화 전체를 보내지 않으므로 매 질문에 필요한 조건을 명확히 적습니다.
- 시나리오·대화는 해당 브라우저에만 저장됩니다. JSON 불러오기는 조건을 복원하고 기존 대화는 유지합니다.

## 계산 범위와 남은 확인

가상 고객 한 사례의 부분 검증 모델입니다. 과거 가입분의 B값 비중과 2026년 추납 계수를 수정했습니다. 세금·보험·주택연금 보간 월액 등은 기획자 최종 확인이 필요합니다. 상세 가정은 웹의 ‘가정과 근거’에서 확인하세요.

운용수익률을 비교안에 공통 적용했으므로 원본 보고서의 설계 후 결과와 다릅니다. 최저 자산은 2026년 구매력, 기말 자산은 명목금액입니다. 음수 자산은 미충당 부족액이며 차입으로 처리하지 않습니다. 주택연금 채무·상속재산은 계산하지 않습니다.

API 제한은 단일 서버 인스턴스 메모리 기준입니다. 대규모 공개 운영 시 영속적인 호출 제한과 사용자 인증이 추가로 필요합니다. 공모전의 공개 조건에 맞춰 배포 접근 범위를 정하세요.

실제 AI 호출은 배포 환경의 키·모델 설정과 계정별 사용 한도에 따라 달라집니다.
