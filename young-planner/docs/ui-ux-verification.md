# UI/UX 개선 검증 — 2026-11-05

## 바꾼 이유와 동작

- 선택 여부가 보이지 않던 예시 버튼을 실제 상태와 연결했습니다. 예시는 초록색·체크 표시, 가구 정보 수정 시 직접 입력으로 전환합니다. 상단 모드 배지는 제거했습니다.
- 중복 진단 카드와 긴 단일 화면 대신 핵심 지표 아래에서 결과 비교·은퇴 계획·가정과 근거를 선택합니다. ‘해법’은 ‘은퇴 계획’, ‘준비 방법’으로 바꿨습니다.
- 숫자만 있는 입력 단계 대신 이름이 있는 묶음을 펼쳐 수정합니다. 계산에 쓰이지 않던 근속연수 입력은 화면에서 제거했습니다. 구직급여·재취업·추납의 금액과 기간은 해당 준비 방법 안에서 조절합니다.
- 그래프는 준비 전·선택 계획을 같은 축에서 비교하고 선 종류와 범례를 구분합니다. 기본은 겹쳐 보기이며 나란히 보기도 지원합니다. 수익률 차이도 결과에 포함됨을 표시합니다.
- 금액·비율 표시는 소수점 최대 한 자리입니다. 원래 예시 계산값과 내보내는 조건·월별/검증 CSV의 정밀도는 보존합니다.
- 레거시 페이지·이전 사례 API/도구·설명 전용 API를 제거했습니다. AI는 현재 가구 입력을 사용하는 에이전트 경로 하나로 정리했습니다. API 미설정·실패를 계산 설명으로 대체하지 않습니다.
- AI는 도구로 계산한 후보를 제시합니다. 후보의 변경 전후 조건, 최초 부족월·최저·기말 자산을 확인하고 적용·되돌리기를 할 수 있습니다. 입력이 달라진 과거 후보는 적용하지 못하게 막습니다.
- Enter 전송, Shift+Enter 줄바꿈, 한글 조합 중 전송 방지를 적용했습니다. 분석 중단·오류·재시도·적용 완료 상태를 구분합니다.
- 모바일 설정·AI는 닫기/Escape와 키보드 포커스 이동을 지원하는 창으로 열립니다. 데스크톱 AI 높이는 스크롤 위치에 맞춰 바뀌며 입력창을 화면 안에 유지합니다.

## 실제 브라우저 확인

- 예시 → 직접 입력 → 생활비 변경 → 예시 복원. 선택 버튼의 `aria-pressed=true`와 녹색 배경, 원래 계산값 복원 확인.
- 재취업 선택 해제 후 최초 부족월·최저·기말 자산 즉시 변경 확인. 보고서 기본 계획 복원 확인.
- Enter 전송·Shift+Enter 줄바꿈, 키가 없는 실제 로컬 서버의 503 안내와 재시도 표시 확인. 계산 설명 대체 응답 없음.
- 외부 호출 없는 임시 로컬 모의 AI로 비교 도구 → 실제 계산 후보 카드 → 변경 조건 펼치기 → 적용 → 되돌리기 확인. 이후 모의 서버 종료 및 원래 환경으로 재시작.
- 390×844 및 320×740에서 가로 넘침 없음. 모바일 설정/AI 열기·닫기, Escape 후 포커스 복원, 입력창 가시성 확인.
- 생활비 0 입력 시 ‘50만 원 이상’ 안내와 잘못된 입력 상태 확인.
- 데스크톱에서 AI를 열어도 입력창이 뷰포트 안에 표시되는 것을 확인.

실제 외부 AI 응답은 로컬 API 키가 없어 검증하지 못했습니다. 제공자 연결은 서버에 키·모델 설정 후 별도 확인이 필요합니다. 모의 응답은 동작 검증에만 사용했으며 현재 로컬 실행 환경에는 남겨 두지 않았습니다.
