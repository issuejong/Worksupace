# 계산 에이전트 v1

2026-11-03. 현재 가상 고객의 410개월 부분 검증 모델을 유지한다.

## 도구와 탐색

현재 조회, 변경안 계산, 최대 12개 안 비교, 조합 탐색, 생활비 한도, 스트레스 테스트를 지원한다. 수급 여부·재취업 여부·소득·생활비·수익률은 기본 고정한다. 재취업 선택 탐색은 명시 요청 시에만 허용한다. 조합 탐색은 상환·추납과 주택연금 미가입/등록된 세 시점/현재 시점의 유한 후보를 계산한다. 가입 연도와 월액은 함께 유지한다. 순자산 최적화와 실제 자격 판정은 지원하지 않는다.

기말 명목금융자산 또는 최저 실질금융자산 목표를 지원한다. 자산 부족 금지와 비상자금 충족 제약을 선택할 수 있다. 생활비는 월 50~2000만 원 범위, 0.01만 원 단위로 탐색하며 범위 내 해가 없으면 명시한다.

## 실행과 적용

모델 호출 최대 4회, 도구 호출 최대 6회, 전체 요청 시간 45초. Zod 입력 검증. 임의 코드·URL 실행 없음. 후속 모델 호출 실패 시 완료한 계산을 반환하고 현재 설정은 유지한다. 분석/탐색 요청은 자동 적용하지 않는다. 명시 변경 요청이나 사용자의 후보 적용으로 변경한다. 분석 당시 조건과 달라진 경우 재계산을 요구한다.

현재 조건, 최근 대화, 구조화된 계산 결과와 도구 인자를 저장한다. 오래된 대화의 숫자는 계산 근거로 재사용하지 않는다. 전체 결과는 대화 JSON에서 확인할 수 있다. 화면 카드가 실제 계산값의 근거이며 자연어 답변은 모델 생성이다. 공식 자료 실시간 조회는 2차 범위이다.

## 검증

임시 로컬 복제 환경에서 26개 테스트 통과, TypeScript 검사 통과, Next.js production build 성공. 원본 폴더의 파일 읽기 지연을 피하고 같은 lockfile로 npm ci한 환경을 사용했다. 기존 월별 원본 대조 테스트를 포함한다.

운영 Gemini 실제 호출에서 16개 조합 탐색, 상위 후보 표시, 조회 시 설정 보존을 확인했다. 후보 적용으로 2031년 가입, 되돌리기로 기존 2027년 가입 조건 복구를 확인했다.
