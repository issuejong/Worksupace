| -------- | ------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| 필수     | 최종 검증 기준은 최신 첨부본인가요? 요청문의 부족액 2억7,306만원·최저자산3,789만원의 출처는 무엇인가요? | v11: 설계 전2031.2 부족, 생애 순 부족액29,398.8546만원 / 설계 후 최저3,616.5519만원, 생애 순수지+5,556.7208만원                        |

| 필수     | 조기수령 소득·가입기간 자격을 사용자가 확인하는 방식으로 둘까요?                                        | 개시월과 감액/가산만 비교, 자격 별도 확인 안내. 소득에 따른 지급정지 등 정밀 계산 제외                                                 |

| 확인     | 생애 순수지는 운용수익을 빼는 보고서 정의로 확정할까요?                                                 | 시작금융자산+월별 실질(수입-지출-운용수익). 기말 금융자산과 구분                                                                       |

모든 예시값은 사용자가 확인한 값으로 대체해야 한다. 실제 정책·지급액을 최종 확정했다고 표시하지 않는다.
