# AI 요청 실패 보완 — 2026-11-05

운영 `/api/agent` 오류 로그의 실행 리전은 `icn1`(서울). `iad1`로 표시되는 빌드 위치와는 다르며, 외부 AI 제공자의 데이터 처리 위치를 뜻하지 않는다.

최근 30분 조회에서 제공자 HTTP 503 오류 3건, 입력 수집 응답의 배우자 날짜 null/빈 문자열 검증 오류 2건을 확인했다. 개인정보 입력값과 API 키는 기록하지 않는다.

- 수집 응답의 null/빈 문자열은 누락으로 처리한다. 확실히 검증된 값만 확인 카드에 남긴다.
- 연도만 있는 날짜·범위 밖 금액은 추정하지 않고 제외한 뒤 다시 질문한다. 유효한 다른 값은 유지한다.
- 408/500/502/503/504 오류는 0.75~1.25초 대기 후 한 번만 재시도한다. 전체 50초 제한·사용자 중단 신호를 유지한다. 400/401/403/429는 자동 재시도하지 않는다.
- 응답 형식 오류, 제공자 일시 오류, 시간 초과를 구분해 표시한다. 질문과 기존 입력은 유지한다.
- 계산 로직, 모델, 제공자, 요금제, 리전 설정은 변경하지 않는다. 제공자 장애의 완전한 제거를 보장하지 않는다.

회귀 검사: 55개 테스트. null/빈 문자열+0원 유지, 미완성 날짜와 잘못된 금액 분리, 503 복구·상한, 사용량/인증 오류 재시도 제외, 중단 시 재시도 취소, API 응답 상태/카드 검증 포함.
