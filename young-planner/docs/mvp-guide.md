# Young Planner MVP 사용·검증 가이드

1. 권 부장 부부 예시로 체험을 누르면 보고서v11의 가정으로 복원됩니다.
2. 내 정보로 계산을 누르고 네 단계에서 가족·소득·자산·연금을 수정합니다. 수정 전 값은 예시입니다.
3. 세부 조건에서 대출 금리·기간, 전후 수익률, 추납 비용·월액, 구직급여 등 가정을 확인합니다.
4. 해법을 켜거나 국민연금 수령 시기·주택연금 가입 연도를 바꾸면 즉시 다시 계산됩니다.
5. 두 그래프는 같은 축입니다. 부족월·최저 자산·생애 순수지, 비상자금 상태를 함께 봅니다.
6. AI 설명은 설정을 바꾸지 않습니다. 전송을 선택하지 않으면 엔진의 상담 메모를 제공합니다. AI가 실패해도 계산과 기본 설명은 유지됩니다.
7. 월별 CSV, 예시 검증 대조표 CSV, 상담 메모를 내려받을 수 있습니다. 인쇄 메뉴에서 결과를 PDF로 저장할 수 있습니다.

신규 입력과 대화는 자동 저장하지 않습니다. 조건을 남기려면 JSON 저장을 직접 선택하세요. 이전 스키마 JSON은 /legacy에서 열 수 있으며 이전 브라우저 저장 키는 변경하지 않습니다.

검증: npm test, npm run typecheck, npm run build. tests/report-v11.json은 제공 엑셀의 저장된 월별 결과를 추출한 원본 대조 자료입니다. 설계 전+E1~E6 각410개월 금융자산을1원 이내로 비교하며, 요약 지표와 이벤트 월·경계를 별도 검증합니다. 최종 제출 전 Excel에서 재계산한 파일로 자료를 갱신해야 합니다.

보고서 캡처 권장: 예시 설계 전 진단 / 동일 축 전후 비교 / AI 상담 메모. docs/team-questions.md에 미확정 사항을 정리했습니다.
