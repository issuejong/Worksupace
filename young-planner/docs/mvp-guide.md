# Young Planner 사용 안내

1. **권 부장 부부 예시 넣기**을 누르면 예시 정보와 보고서 기본 계획을 불러옵니다. 옆의 **예시 소개**에서 가족 상황과 주요 금액을 확인할 수 있습니다.
2. **내 정보 확인·수정**에서 입력 항목을 펼쳐 수정합니다. 처음 값은 예시이므로 본인 정보로 바꿔 주세요. 금액 단위는 만 원입니다.
3. **은퇴 계획**에서 우리 부부가 사용할 준비 방법을 체크합니다. 비용·월액·기간은 각 항목 아래에서 조절합니다. **보고서 기본 계획 적용**은 가구 정보를 유지하고 준비 방법만 되돌립니다. 상단 예시 버튼은 가구 정보까지 초기화합니다.
4. **결과 비교**에서 처음 부족해지는 달, 가장 적게 남는 돈, 마지막 금융자산을 확인합니다. 그래프는 준비 전·선택 계획을 같은 축으로 비교합니다. **나란히 보기**도 가능합니다.
5. 오른쪽 아래 **로봇 버튼**을 눌러 **은퇴 챗봇**에서 “재취업 없이 비교해 줘”, “2031년 2월 지출이 왜 많아?”, “마지막 자산이 가장 많이 남는 계획을 찾아줘”처럼 질문합니다. Enter는 전송, Shift+Enter는 줄바꿈입니다. 서버에 키가 없으면 연결 안내가 나옵니다.
6. AI 후보 카드에서 **변경 조건**을 확인한 뒤 **이 계획 적용**을 누릅니다. **되돌리기**로 적용 전 조건을 복원합니다. 다른 조건을 직접 수정하면 되돌리기는 종료됩니다. 조건이 바뀐 과거 분석은 적용할 수 없습니다.
7. **가정과 근거**에서 월별 표·계산 범위를 확인하고 월별 CSV·예시 대조표를 내려받거나 화면을 인쇄합니다. 조건 저장·불러오기는 입력 패널 아래에 있습니다.

챗봇 버튼과 채팅창은 PC·모바일 모두 화면 오른쪽 아래에 고정됩니다. 페이지를 스크롤해도 같은 위치에 유지되며 채팅창을 연 채로 결과를 스크롤할 수 있습니다. 로봇 버튼을 다시 누르거나 창의 닫기 버튼·Escape로 닫습니다. 다시 열면 대화와 작성 중인 질문이 유지됩니다. 모바일 입력 설정은 별도 창으로 열립니다.

최저 자산·평생 수지와 그래프는 계산 시작 연도의 구매력입니다. 마지막 금융자산은 해당 연도의 명목금액입니다. 비상자금 목표 미달과 자산이 0 아래로 내려가는 상태는 구분합니다. 주택연금 채무를 뺀 순자산은 아닙니다.

화면은 소수점 최대 한 자리로 표시하고 원래 계산 정밀도를 유지합니다. 조건 파일·월별 CSV·검증 대조표는 원래 수치를 보존합니다. 입력·대화를 브라우저나 서버 DB에 자동 저장하지 않습니다. 질문 전송 시 현재 가구 조건과 같은 조건에서 나눈 최근 대화가 AI 제공자에게 전달됩니다.

검증 자료는 제공된 엑셀의 저장 결과입니다. 최종 제출 전 재계산한 Excel 파일로 갱신해야 합니다. 미확정 가정은 [팀 확인 질문](team-questions.md)에 있습니다.
