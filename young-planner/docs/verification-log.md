# 구현 검증 기록

2026년 11월 3일 기준.

- 원본 E1~E6의 410개월 금융자산: 1원 이내 오차로 재현하는 테스트 통과.
- 과거 국민연금 B값 비중과 추납 계수 부분 수정: 독립 계산 결과 대조 통과.
- 대출 상환월, 재취업 지연, 의료비 충격, 입력 오류, API 설정 누락·접근 제한: 테스트 통과.
- 총 15개 테스트, TypeScript 검사, Next.js 프로덕션 빌드 통과.
- 의존성 감사: 설치 후 발견된 테스트 의존성 취약점 수정, 0건.
- 브라우저에서 생활비 250→280만 원 변경 시 자산·고갈 시점·비상자금 판정 갱신과 기본값 복원 확인.
- 브라우저에서 7개 시나리오와 월별 상세표 표시 확인.
- 구직급여를 재취업과 독립된 스위치로 분리해 S0에는 추가 대책을 적용하지 않도록 수정.

실제 API 키가 제공되지 않아 유료 OpenAI 응답은 검증하지 않았다. 배포 계정 설정도 없어 Vercel 배포는 실행하지 않았다. 금융 제도의 최종 확인은 남아 있으며 화면에 부분 검증 상태와 가정을 표시한다.

1차 UI는 전역 CSS와 기본 HTML 컨트롤로 구현했다. 계획의 Tailwind·shadcn 컴포넌트 전환은 필수 기능에 영향을 주지 않아 후속 개선으로 남겼다. AI는 시나리오 계산·전후 비교를 한 함수 도구로 처리하며 근거는 등록된 공식 링크를 프롬프트로 전달한다. 대화 전체 문맥 전달과 별도 근거 검색 도구는 후속 범위다.


## 2026-11-05 일반 가구 MVP

- 작업 엑셀 v1.1 / 본문 v11의 설계 전+E1~E6, 총2,870개월 금융자산을 대조했다. 최대 오차0.004422원, 1원 초과 차이0건. 이는 제공 파일의 저장된 계산 결과 기준이며 최종 제출 전 Excel 재계산본 대조가 필요하다.
- 전체46개 테스트 통과. TypeScript 검사와 최종 Next.js 프로덕션 빌드 통과.
- PC와390px 모바일에서 생활비 변경, 음수 입력 오류 및 복원, 주택연금 해제, 조기연금 수령, 설명 패널 열기/닫기와 계산 기반 상담 메모를 확인했다. 가로 넘침 없음, 두 그래프 SVG 렌더링 및 동일 축 확인.
- AI 응답의 임의 숫자 거부·사실 식별자 치환과 API 키 누락 대체 설명은 테스트로 확인했다. 로컬 실계정 LLM 호출은 API 키가 없어 검증하지 않았다.
- 예시 기준: 설계 전2031.2 최초 부족 / 생애 순수지−29,398.8546만원, 설계 후 최저3,616.5519만원 / 생애 순수지+5,556.7208만원.
- 기존 사례 및 저장 데이터는 /legacy 유지. 신규 입력은 메모리 상태와 사용자가 직접 저장하는 JSON만 사용.
- 보고서용 캡처3장: docs/screenshots. 팀 확인 질문: docs/team-questions.md.
- 로컬 검증까지만 진행했으며 푸시·배포하지 않았다.
